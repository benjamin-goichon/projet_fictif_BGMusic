# projet_fictif_BGMusic

Un projet de boutique en ligne fictive, réalisé pour m'entraîner en HTML et CSS. La boutique vend des instruments de musique.

## Technologies

- HTML5 (balises sémantiques : `header`, `main`, `section`, `article`, `footer`)
- CSS3 (flexbox, variables CSS, positionnement, transitions)
- Convention de nommage BEM, décrite dans `nomenclature.md`

## État d'avancement

- [x] Header (logo, navigation, panier)
- [ ] Section principale (`main`) : affichage des produits, en cours
- [ ] Footer : à faire

## Structure du projet

```
projet_fictif_BGMusic/
├── css/          feuilles de style
├── html/         pages HTML
├── ressources/   images et autres fichiers utilisés par la boutique
└── nomenclature.md   règles de nommage des classes (BEM)
```

## Lancer le projet

Ouvre le fichier HTML principal du dossier `html/` dans ton navigateur. Aucune installation n'est nécessaire.

## Ce que j'ai appris avec ce projet

- Organiser une page avec des balises sémantiques.
- Aligner et répartir des éléments avec flexbox, y compris imbriqué.
- Nommer les classes avec BEM pour garder un CSS lisible.
- Positionner un élément par rapport à son parent (`relative`, `absolute`) et gérer l'ordre d'affichage (`z-index`).
